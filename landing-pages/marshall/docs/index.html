Privacy By Architecture

Not a fork. Not a skin. Built from scratch in Rust for security-first browsing.

🚫

Built-in Ad Blocking

EasyList-powered filter engine runs natively. No extension overhead. Blocks ads, trackers, and malware domains.

🧅

Tor Integration

One-click Tor circuit. Route all traffic through onion network. DNS-over-Tor, SOCKS5 proxy chain support.

👤

Anti-Fingerprinting

Canvas, WebGL, and Audio API protection. WebRTC leak prevention. mDNS ICE candidates only.

🔒

Tab Isolation

Each tab runs in its own process sandbox. Cookie isolation prevents cross-site tracking. Clear-on-exit by default.

🤖

Dr. Marshall AI

Built-in AI assistant sidebar for research, summarization, and security analysis. Runs locally — no cloud calls.

🔬

OSINT Research Suite

Right-click Shodan lookup, WHOIS, DNS enumeration, SSL cert analysis, Wayback Machine, VirusTotal integration.

🛡️

Extension Sandbox

Extensions run in isolated containers with honeypot detection for malicious add-ons. Permission-gated API access.

🔐

DNS-over-HTTPS

DNSSEC validation, certificate pinning, HSTS preload list. No plaintext DNS queries ever leave your machine.
