STEP 1: Build the ISO
──────────────────────────────────────────────────────────────────────────
Run this command:

    cd ~/nullsec && bash build-iso.sh

This will create a fresh ISO in the background with all v2.0 enhancements.
Time required: 30-60 minutes

STEP 2: Copy to "The Lulz Boat" USB
──────────────────────────────────────────────────────────────────────────
Once ISO creation completes, run:

    sudo bash ~/nullsec/copy-iso-to-lulzboat.sh

This automatically copies the ISO to your USB drive.

🐛 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Problem: Process stopped or interrupted
Solution: Run build-iso.sh again - it will clean up and restart

Problem: Not enough disk space
Solution: You need ~20GB free on /home partition
Check with: df -h /

Problem: ISO creation fails
Solution: Check logs in ~/nullsec/iso-build.log
