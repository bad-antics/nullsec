# 📡 NullSec WiFi — OpenClaw Skill

Wireless security assessment skill for OpenClaw/Clawd. Complete WiFi pentest methodology with Hak5 Pineapple integration and 183+ pre-built payloads.

## Features

- **WPA/WPA2/WPA3 testing** — Handshake capture, PMKID, dictionary attacks
- **Evil twin & rogue AP** — Automated setup with captive portal
- **Enterprise 802.1X** — RADIUS/EAP testing, credential capture
- **Hak5 Pineapple** — 183+ payload deployment and management
- **Detection** — Rogue AP scanning, deauth monitoring
- **5GHz support** — Full dual-band coverage

## Installation

### Via ClawHub
Search for `nullsec-wifi` on [ClawHub](https://clawhub.com)

```bash
cp -r nullsec-wifi/ ~/.config/openclaw/skills/
```
