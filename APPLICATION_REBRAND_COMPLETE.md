## ⚠️ Known Acceptable References

The following contain "Parrot" and **cannot/should not** be changed:

### 1. Kernel Version String
```bash
uname -a
```
Shows "Parrot" because it's compiled into the kernel binary. Changing requires kernel recompilation from source.

### 2. Package Names (Internal)
Some Debian package names retain "parrot" prefix:
- `parrot-tools`
- `parrot-menu`
- `parrot-core`

These are internal package managers identifiers and don't affect user experience.

### 3. Binary Compiled Strings
Some compiled binaries may contain hardcoded "Parrot" strings in metadata. These are harmless and invisible to users.

### 4. Historical Documentation
Some `/usr/share/doc` changelog files reference "Parrot" in historical entries. These are appropriate historical references.
